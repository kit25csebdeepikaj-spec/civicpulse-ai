# CivicPulse

**An agentic AI platform for citizen grievance redressal** — built for the Innovik Hackathon.

CivicPulse replaces slow, manual complaint triage with six specialized AI agents that intake, classify, prioritize, route, and respond to citizen grievances automatically — while giving officials a live dashboard of hotspots and trends.
